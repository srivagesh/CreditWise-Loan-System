CreditWise Loan System

About the Project

CreditWise Loan System is a machine learning project that predicts loan approval based on applicant details. The project involves analysing loan data, understanding the factors that influence loan approval, and building a model to make predictions.

Technologies Used

Python, Jupyter Notebook, Pandas, NumPy, Matplotlib, Seaborn and Scikit-learn.

Project Files

credit_wise.ipynb – Contains the code and implementation of the project.

CreditWise Loan System.pdf – Contains the project documentation.

Dataset

The dataset used for this project is not included in the repository.

How to Run

Download or clone the repository and open the credit_wise.ipynb file in Jupyter Notebook. Make sure the required dataset and Python libraries are available before running the notebook.
