\# CreditWise Loan System



\## Project Overview

CreditWise Loan System is a Machine Learning project designed to analyze loan applicant information and predict loan approval status.



The system uses historical loan application data to understand patterns and support loan approval predictions.



\## Objectives

\- Analyze loan applicant information.

\- Perform data preprocessing and exploratory data analysis.

\- Apply Machine Learning techniques for loan approval prediction.

\- Evaluate the model's performance.



\## Technologies Used

\- Python

\- Jupyter Notebook

\- Pandas

\- NumPy

\- Matplotlib

\- Seaborn

\- Scikit-learn



\## Project Files

\- `credit\_wise.ipynb` – Jupyter Notebook containing the project implementation.

\- `CreditWise Loan System.pdf` – Project documentation.



\## Dataset

The dataset used for model development is not included in this repository.



\## How to Run

1\. Clone this repository.

2\. Install the required Python libraries.

3\. Open `credit\_wise.ipynb` using Jupyter Notebook.

4\. Run the notebook cells.
